📷 গ্যালারি আপলোড: ফোনের গ্যালারি থেকে ছবি বাছলে অটোমেটিক ছোট করে একটা ইনলাইন লোগো URL বানিয়ে বসিয়ে দেবে — সাথে সাথে কাজ করে, কোনো ইন্টারনেট/আপলোড লাগে না। তবে এটা আমাদের এই অ্যাপে সবসময় ঠিকমতো দেখাবে, কিন্তু কিছু বাইরের IPTV app-এ (VLC/Smarters ইত্যাদি) এই ধরনের ইনলাইন লোগো নাও দেখাতে পারে — সেসব app-এর জন্য imgbb.com/ibb.co-তে ছবি আপলোড করে সেই লিংক ব্যবহার করাই সবচেয়ে নিরাপদ।

📁 গ্যালারি আপলোড: ফোনের গ্যালারি থেকে সরাসরি ছবি বেছে নিলে সেটা থেকে অটোমেটিক একটা Logo URL বানিয়ে বসিয়ে দেবে (কোনো ইন্টারনেট আপলোড লাগে না, ছবিটা লিংকের ভেতরেই এমবেড থাকে)। এটা আমাদের এই অ্যাপে এবং যেসব IPTV app এই ধরনের লিংক সাপোর্ট করে সেগুলোতে ঠিকমতো দেখাবে। তবে সব IPTV app সাপোর্ট নাও করতে পারে — সর্বোচ্চ compatibility-র জন্য নিচের "GitHub Logo URL" পদ্ধতিতে একটা সাধারণ https লিংক বানানোই সবচেয়ে নিরাপদ।

☁️ GitHub Repo-তে Upload করুন (সব জায়গায় দেখাবে)

গ্যালারি থেকে ছবি বাছার পর এখানে আপলোড করলে ছবিটা আপনার নিজের GitHub repo-তে সেভ হয়ে একটা স্থায়ী পাবলিক লিংক পাবে (raw.githubusercontent.com) — এই লিংক যেকোনো IPTV app, ওয়েবসাইট বা ডিভাইসে দেখাবে, কারণ এটা একটা সাধারণ পাবলিক ছবির URL।

Token বানাতে: GitHub → Settings → Developer settings → Personal access tokens → Generate new token (classic) → শুধু "repo" (বা public repo হলে "public_repo") পারমিশন টিক দিন। Token কোথাও সেভ হয় না, আপলোডের পর মুছে যাবে।

GitHub Logo URL বানানোর সহজ নিয়ম

Repository-তে PNG/JPG আপলোড → ছবির GitHub page খুলুন → Raw চাপুন → address bar-এর URL কপি করুন। অথবা নিচের মতো GitHub blob URL paste করে Convert চাপুন।

উদাহরণ: github.com/user/repo/blob/main/logos/ntv.png → raw.githubusercontent.com/user/repo/main/logos/ntv.png

🧩 নিজের মতো ক্যাটাগরি করে প্লেলিস্ট তৈরি করুন

বাম পাশ থেকে চ্যানেল বেছে ডান পাশে যোগ করুন (➡️ চাপুন, বা মাউস দিয়ে টেনে আনুন)। ডান পাশে প্রতিটা চ্যানেলের নিচে বক্সে নিজের পছন্দমতো ক্যাটাগরি/গ্রুপের নাম লিখতে পারবেন। শেষে নাম দিয়ে প্লেলিস্ট হিসেবে সেভ করুন অথবা সরাসরি .m3u ফাইল ডাউনলোড করুন — যেকোনো IPTV app (VLC, IPTV Smarters, TiviMate ইত্যাদি) বা ডিভাইসে এই ফাইল চালানো যাবে।

নিচে ক্যাটাগরি অনুযায়ী ফোল্ডার আকারে চ্যানেল দেখানো হচ্ছে — পুরো ক্যাটাগরি একসাথে যোগ করতে ক্যাটাগরির পাশের বাটনে চাপুন, অথবা একটা একটা চ্যানেল বেছে নিতে চ্যানেলের পাশের ➡️ বাটনে চাপুন।

🔍 Dead Channel Checker

প্রতিটা চ্যানেলের স্ট্রিম URL-এ রিকোয়েস্ট পাঠিয়ে যাচাই করা হবে সাড়া দিচ্ছে কিনা। ৪ ধরনের ফলাফল হতে পারে: ✅ Live (সত্যিই সাড়া দিচ্ছে), ❌ Dead (সত্যিই বন্ধ — কোনো ভাবেই সাড়া পাওয়া যায়নি), ❔ অজানা (সার্ভার CORS ব্লক করছে, তাই ব্রাউজার থেকে ১০০% নিশ্চিত হওয়া যায়নি — চলতেও পারে), 🔒 HTTP-অযাচাইকৃত (এই চ্যানেলের লিংক http:// যা আপনার https:// সাইট থেকে ব্রাউজার-নিরাপত্তার কারণে (Mixed Content) চেক করাই যায় না — এটা "Dead" না, শুধু যাচাই করা সম্ভব হয়নি, VLC/IPTV app-এ ঠিকই চলতে পারে)। চ্যানেল সংখ্যা বেশি হলে একটু সময় লাগবে।
